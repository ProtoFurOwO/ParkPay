🚀 PASOS PARA INICIAR:

1. ⚠️ PREREQUISITO: Instalar Node.js
   → https://nodejs.org/ (Versión LTS)
   → Reiniciar computadora después de instalar

2. 📦 Configurar Base de Datos PostgreSQL
   → Ejecutar: c:\masm\BIN\base postgre.sql
   → Ejecutar: backend\init_db.sql

3. ⚙️ Configurar Credenciales
   → Editar: backend\.env
   → Cambiar: DB_PASSWORD=tu_password_aqui

4. 📥 Instalar Dependencias
   → Abrir terminal en carpeta PP\backend
   → Ejecutar: npm install

5. ▶️ Iniciar Aplicación
   → Doble clic en: INICIAR_SERVIDOR.bat
   → Doble clic en: ABRIR_APP.bat

🎬 FLUJO DE USO:

1. Usuario se registra con sus datos personales y vehículo
2. Inicia sesión con email y contraseña
3. Ve el mapa con todos los cajones disponibles
4. Selecciona un cajón verde (disponible)
5. Elige las horas estimadas
6. El sistema calcula el costo automáticamente
7. Confirma el pago
8. Recibe código de acceso único
9. El cajón se marca como ocupado (rojo)
10. Los datos se guardan en PostgreSQL

═══════════════════════════════════════════════════════════════════════════════

🌐 ENDPOINTS DE LA API:

POST   /api/auth/register              - Registrar usuario y vehículo
POST   /api/auth/login                 - Iniciar sesión
GET    /api/cajones                    - Obtener todos los cajones
GET    /api/cajones/piso/:piso         - Cajones por piso (A o B)
POST   /api/tickets                    - Crear ticket (ocupar cajón)
GET    /api/tickets/usuario/:id        - Tickets de un usuario
PATCH  /api/tickets/:id/finalizar      - Finalizar ticket (liberar cajón)
POST   /api/tickets/calcular-costo     - Calcular costo estimado
